# Home Project Calculator

A responsive web application for estimating materials and costs for home improvement projects. Built with Next.js, React, and TypeScript.

## Features

- 15 home improvement calculators
- Material quantity and project cost estimation
- Metric and imperial measurement options
- Save, edit, and compare project estimates
- PDF printing and CSV export
- Calculator search and unit converter
- Project planning assistant
- Responsive design with light and dark modes

## Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Styling:** CSS
- **Icons:** Lucide React
- **Storage:** Browser Local Storage

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the application.

## Testing

```bash
npm run check
npm test
npm run build
```

The project includes automated tests for calculator calculations, input validation, and result formatting.

## Notes

Project estimates are intended for planning purposes and should be verified against actual material prices and professional advice.

Saved estimates are stored locally in the user's browser. No cloud synchronization is provided.
